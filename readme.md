#  AI Job Recruitment Website

> A modern recruitment platform powered by AI (RAG chatbot) to transform the way candidates search for jobs and employers find talent.

---

##  Project Information

- **Project Name:** AI Job Recruitment Website  

---

##  Description

This project is a **smart job recruitment platform** that integrates an **AI chatbot using Retrieval-Augmented Generation (RAG)** to enhance the job search experience.

Unlike traditional systems that rely on keyword filtering, this platform allows users to:
- Search jobs using **natural language**
- Receive **intelligent and structured results**
- Interact with an AI assistant for better job discovery

---

##  Project Goal

The goal is to build a **modern recruitment ecosystem** that connects:

-  Candidates → Find jobs efficiently  
-  Employers → Find suitable candidates  
-  AI Chatbot → Enhance search with semantic understanding  

---

##  Core Features

###  Candidate
- Register / Login / Logout
- Manage profile:
  - Skills
  - Education
  - Experience
  - Certificates
- Search jobs:
  - Keyword-based
  - AI chatbot (natural language)
- Apply for jobs
- Track application status

---

###  Employer
- Manage company account
- Post job listings
- View candidate applications

---

###  AI Chatbot (RAG)
- Natural language job search (**Vietnamese supported**)
- Extract user intent:
  - Location
  - Salary
  - Role
  - Experience
- Use:
  - LLM (semantic parsing)
  - Vector Database (semantic search)
- Return structured filters for backend querying
